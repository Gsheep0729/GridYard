# 鸽邮（GridYard）

局域网文件互传工具的项目仓库：目标是无账号、零配置的局域网设备发现与文件
传输，覆盖单发、群发与传输管理，并兼顾跨网段场景。技术选型为 Qt6/QML 界面
与 C++ 核心，网络采用 Boost.Asio。
