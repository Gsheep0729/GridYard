# GridYard 文件传输测试流程

## 前置条件

1. 两台电脑在同一局域网（或同一台电脑用不同端口测试）
2. 已构建项目：`cmake --build src/build-ninja -j`
3. 单机双实例测试时，每个实例必须使用不同且稳定的 `--config` 文件

## 测试步骤

### 1. 启动两个实例

```bash
# 终端 1：启动接收端
./src/build-ninja/client/appGridYard \
  --config ~/gridyard_receiver.ini \
  --port 35100 \
  --name "接收端"

# 终端 2：启动发送端
./src/build-ninja/client/appGridYard \
  --config ~/gridyard_sender.ini \
  --port 35101 \
  --name "发送端"
```

### 2. 验证设备发现

- 两个实例启动后，检查设备列表是否显示对方
- 确认对方设备显示为"在线"状态

### 3. 测试拖拽文件传输

1. 在发送端，从文件管理器拖拽一个 PDF 文件到接收端的设备卡片
2. 观察控制台日志，确认以下流程：
   - `[TransferSession] 创建发送会话`
   - `[TransferSession] 目标设备ID: xxx`
   - `[FileSender] 开始传输流程`
   - `[FileSender] 连接成功`
   - `[FileSender] 传输请求已发送`

3. 在接收端，应该弹出确认对话框
4. 点击"接受"后，观察日志：
   - `[FileReceiver] 用户接受传输`
   - `[FileReceiver] 开始接收文件`
   - 传输进度更新
   - `[FileReceiver] 文件接收完成`

### 4. 测试文件选择器发送

1. 在发送端选中接收端设备，进入右侧会话页
2. 点击发送菜单，选择"发送文件"
3. 在系统文件选择器中一次选择 2-3 个文件，文件名至少包含一个中文或空格
4. 接收端逐个接受传输，确认所有文件都进入传输列表并完成

### 5. 测试文件夹选择器发送

1. 在发送端点击发送菜单，选择"发送文件夹"
2. 选择一个包含子目录、空文件和中文文件名的目录
3. 接收端接受传输
4. 传输完成后检查目录结构、空文件和文件名是否保持一致

### 6. 测试接收路径选择器

1. 在接收端打开设置页
2. 点击"更改目录"，选择一个路径中包含中文或空格的目录
3. 保存设置后重新发送一个文件
4. 确认文件保存到新接收路径

### 7. 验证结果

- 发送端显示"文件 XXX 发送成功"绿色弹窗
- 接收端显示"文件 XXX 接收成功"绿色弹窗
- 检查接收端设置页中的接收路径是否有接收到的文件
- 传输历史中能看到本次文件和文件夹记录

## 常见问题排查

### 问题 1：拖拽后没有反应

**可能原因**：
- TransferSessionManager 未初始化
- 设备不在线
- 拖拽目标不是设备卡片或会话发送区域

**排查方法**：
- 检查控制台是否有 `[TransferSession] 创建发送会话` 日志
- 确认目标设备显示为"在线"

### 问题 1.1：点击发送文件或发送文件夹没有弹出选择器

**可能原因**：
- 运行环境缺少 Qt Quick Dialogs 运行时模块
- 打包时未带上 Qt dialogs QML 模块或平台插件

**排查方法**：
- 确认构建已链接 `Qt6::QuickDialogs2`
- 从终端启动程序，查看是否有 `QtQuick.Dialogs` 导入失败日志
- 开发环境下重新运行 `cmake --build src/build-ninja --target appGridYard -j`

### 问题 2：连接失败

**可能原因**：
- 防火墙阻止
- 端口被占用
- IP 地址错误

**排查方法**：
- 检查日志中的 IP 地址和端口
- 确认防火墙允许 GridYard 通信
- 尝试关闭防火墙测试

### 问题 3：接收端没有弹窗

**可能原因**：
- TransferSessionManager 未连接 P2pServer 信号
- 接收请求信号未传递到 QML

**排查方法**：
- 检查日志是否有 `[TransferSession] 收到传输请求`
- 确认 `receiveRequestReceived` 信号已连接

### 问题 4：传输中断

**可能原因**：
- 网络不稳定
- 文件被占用
- 磁盘空间不足

**排查方法**：
- 检查日志中的错误信息
- 确认文件未被其他程序打开
- 检查磁盘空间

## 日志文件位置

- 日志文件：`src/build-ninja/client/logs/gridyard_yyyyMMdd.log`
- 控制台实时输出：运行时的终端窗口

## 测试用例

### 测试 1：单个 PDF 文件

- 文件：任意 PDF 文件（建议 1-10MB）
- 预期：成功传输，文件完整

### 测试 2：多个文件

- 文件：通过发送菜单选择 2-3 个不同文件
- 预期：所有文件成功传输

### 测试 2.1：文件夹

- 文件夹：包含子目录、空文件、中文文件名和空格文件名
- 预期：目录结构和文件内容完整恢复

### 测试 3：大文件

- 文件：大于 100MB 的文件
- 预期：传输完成，进度显示正常

### 测试 4：取消传输

- 操作：传输过程中点击取消按钮
- 预期：传输停止，双方显示"已取消"

### 测试 5：拒绝接收

- 操作：接收端点击"拒绝"按钮
- 预期：发送端显示"请求被拒绝"
