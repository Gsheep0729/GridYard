# GridYard v6.8.1 发布交付材料

本目录用于集中放置课程验收、答辩展示和最终发布相关材料。发布分支面向老师和验收人员，内容应保持清晰、可读、可运行，避免混入开发期临时文件和测试过程草稿。

## 目录内容

| 文件 | 用途 |
|:-----|:-----|
| `PPT内容稿.md` | 答辩幻灯片逐页内容，可直接据此制作 PPT |
| `演示视频拍摄方案.md` | 演示视频脚本、镜头顺序、录制参数和压缩方案 |
| `GridYard-v6.8.1.pptx` | 最终答辩 PPT，占位文件名 |
| `GridYard-v6.8.1-demo.mp4` | 最终演示视频，占位文件名 |

## 交付文件命名

```text
doc/delivery/
├── README.md
├── PPT内容稿.md
├── 演示视频拍摄方案.md
├── GridYard-v6.8.1.pptx
└── GridYard-v6.8.1-demo.mp4
```

如果演示视频体积较大，可将视频上传到课程平台或校内网盘，并在本目录补充链接、文件大小和校验信息。PPT 建议保留在仓库中，便于老师拉取发布分支后直接查看。

## 截图素材清单

制作 PPT 前建议先准备以下截图，统一放在 `doc/delivery/screenshots/`：

| 文件名 | 内容 |
|:------|:-----|
| `01-main-window.png` | 主界面和在线设备列表 |
| `02-device-discovery.png` | 双实例或双机互相发现 |
| `03-file-transfer.png` | 文件或文件夹传输过程 |
| `04-chat.png` | 在线聊天界面 |
| `05-history.png` | 聊天记录或传输历史 |
| `06-settings.png` | 设置页中设备别名、端口、接收目录 |
| `07-runtime-paths.png` | 配置、数据库、日志所在系统目录 |

截图不需要追求数量，优先保证清晰、真实、能对应功能说明。

## 最终检查

- PPT 中的版本号统一为 `v6.8.1`。
- 演示视频中展示的是最终 AppImage 或最终压缩包可执行文件。
- 不展示开发期测试目录、临时文档、本地配置文件或无关终端历史。
- 发布说明中明确 AppImage 和压缩包都使用系统标准目录保存配置、数据库和日志。
- 设备别名修改后重启仍能保持，这是最终发布验证中的重点展示项。
