# GridYard 发布交付材料

本目录用于存放课程验收时需要直接查看的发布材料。

建议放置内容：

- 答辩或演示 PPT：`GridYard-v6.8.1-demo.pptx`
- 演示视频：`GridYard-v6.8.1-demo.mp4`
- 最终发布包说明：AppImage 与压缩包的下载位置、运行方式和版本号
- 发布分支整理说明：`release分支发布整理指南.md`

发布分支已保留正式应用源码、README、规格与设计文档、开发心得、UML/API 文档和打包指南；自动化测试代码与详细测试指南保留在开发分支，不放入本分支。

如果视频文件体积过大，优先使用 Git LFS 或在本文件中记录校内网盘/课程平台链接，避免普通 Git 仓库体积膨胀。
