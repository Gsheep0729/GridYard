# GridYard v6.8.1 展示材料制作方案

## 1. 视频制作方案

### 1.1 参数要求

| 参数 | 值 | 说明 |
|------|-----|------|
| 大小限制 | ≤ 50MB | GitHub 上传限制 |
| 时长 | 3-5 分钟 | 建议 3 分钟精华版 |
| 分辨率 | 1280x720 (720p) | 足够清晰且省空间 |
| 帧率 | 15fps | 够用即可 |
| 编码 | H.265 / VP9 | 压缩率高 |
| 音频 | 64kbps AAC 单声道 | 够听就行 |

### 1.2 OBS Studio 录制设置

**输出设置：**
```
分辨率：1280x720
缩放滤镜：双线性
码率控制：CBR
码率：1500-2500 kbps（根据画面复杂度调整）
编码器：硬件加速优先（QSV/NVENC/AMD），省 CPU
```

**快捷操作流程：**
1. 启动两个 GridYard 实例（双开测试）
2. 开始录屏
3. 演示核心功能（参考 1.3）
4. 停止录屏
5. 如超限，使用 ffmpeg 压缩

### 1.3 视频内容大纲（约 3 分钟）

| 时间 | 内容 | 备注 |
|------|------|------|
| 0:00-0:15 | 开场：项目名称、版本、团队 | 字幕或画外音 |
| 0:15-0:45 | 设备发现：启动双实例，自动发现 | 核心功能演示 |
| 0:45-1:30 | 文件传输：单文件 + 文件夹传输 | SHA-256 校验、断点续传 |
| 1:30-2:00 | 在线聊天：发送文本消息 | 消息持久化 |
| 2:00-2:30 | 历史查看：聊天记录、传输历史 | SQLite 本地存储 |
| 2:30-2:45 | 修改设备别名，验证持久化 | 配置文件读写 |
| 2:45-3:00 | 结语：技术亮点、V2 展望 | - |

### 1.4 压缩命令（如果超限）

```bash
# 使用 H.265 二次压缩，目标 50MB
ffmpeg -i original.mp4 \
    -c:v libx265 -crf 28 -preset fast \
    -c:a aac -b:a 64k \
    -movflags +faststart \
    GridYard-v6.8.1-demo.mp4
```

## 2. PPT 制作方案

### 2.1 基本信息

| 项目 | 值 |
|------|-----|
| 幻灯片数量 | 12-15 页 |
| 风格 | 简洁、技术风，可参考项目 UI 色系 |
| 时长 | 15-20 分钟讲解 |

### 2.2 PPT 内容大纲

| 页码 | 标题 | 内容要点 | 老师要求对应 |
|------|------|----------|-------------|
| 1 | 封面 | 项目名称、团队成员及分工、日期 | 工作分工 |
| 2 | 目录 | 导航页 | - |
| 3 | 项目概述 | 一句话介绍 + 功能清单 | 基本/扩展需求 |
| 4 | 竞品对比 | LocalSend、飞秋、QQ 传输 | 差异化 |
| 5 | 技术架构 | 四层架构图（表现/应用/领域/数据） | 软件模型一致性 |
| 6 | 核心模块 | DiscoveryService、P2pServer、FrameCodec | 关键技术 |
| 7 | 协议设计 | TLV 帧格式、首帧分流时序图 | 关键技术 |
| 8 | 数据层设计 | SQLite Schema、Repository 模式 | 软件模型一致性 |
| 9 | 界面展示 | 截图 + 交互流程 | 部署运行测试 |
| 10 | 功能演示要点 | 双开测试、设备发现、传输、聊天、历史 | 基本/扩展需求 |
| 11 | 开发难点与解决方案 | 主要踩坑记录 | 开发心得 |
| 12 | 工作分工 | 每人做了什么、感想 | 工作分工 |
| 13 | 总结与展望 | 当前交付状态、V2 规划 | - |
| 14 | 演示视频入口 | 二维码/链接指向视频 | - |

### 2.3 PPT 制作建议

**风格：**
- 主色调：蓝色系（参考项目 Style.js）
- 代码块用等宽字体
- 截图清晰、标注关键区域
- 图表代替大段文字

**工具：**
- WPS 演示 / Microsoft PowerPoint / Google Slides 均可
- 导出格式：`.pptx`

## 3. 交付文件命名

```
doc/delivery/
├── README.md                    # 本文件
├── GridYard-v6.8.1.pptx        # 幻灯片（< 50MB）
└── GridYard-v6.8.1-demo.mp4    # 演示视频（< 50MB）
```

## 4. GitHub 上传方式

### 4.1 直接上传（推荐，视频 < 100MB 时）

```bash
cd doc/delivery
git add GridYard-v6.8.1.pptx GridYard-v6.8.1-demo.mp4
git commit -m "添加演示幻灯片和视频"
git push
```

### 4.2 如果视频超限，启用 Git LFS

```bash
cd doc/delivery
git lfs track "*.mp4" "*.pptx"
git add *.pptx *.mp4 .gitattributes
git commit -m "添加演示材料"
git push
```

## 5. 上传后验证

```bash
# 检查文件大小
ls -lh doc/delivery/

# 如使用 Git LFS，验证追踪状态
git lfs ls-files
```

**注意：** 老师要求视频 50MB 以内，请务必在 OBS 录制时设置合适码率，或使用 ffmpeg 压缩后再上传。
