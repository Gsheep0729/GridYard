## 概述

- **模块职责**：提供 GridYard 客户端所有 QML 界面组件，包括设备列表、会话页、传输任务卡片、设置弹窗等
- **核心组件**：
  - `Main.qml`（`src/client/Main.qml`）
  - `DeviceCard.qml`（`src/client/ui/DeviceCard.qml`）
  - `PeerListView.qml`（`src/client/ui/PeerListView.qml`）
  - `DeviceSessionView.qml`（`src/client/ui/DeviceSessionView.qml`）
  - `AcceptDialog.qml`（`src/client/ui/AcceptDialog.qml`）
  - `SettingsDialog.qml`（`src/client/ui/SettingsDialog.qml`）
  - `TransferTaskCard.qml`（`src/client/ui/TransferTaskCard.qml`）
  - `TransferPanel.qml`（`src/client/ui/TransferPanel.qml`）
  - `ChatView.qml`（`src/client/ui/ChatView.qml`）
  - `FileTypeIcon.qml`（`src/client/ui/FileTypeIcon.qml`）
- **工具脚本**：
  - `Style.js`（`src/client/utils/Style.js`）
  - `FormatUtils.js`（`src/client/utils/FormatUtils.js`）
- **模块边界**：只负责页面结构、组件样式、属性绑定和用户交互，不直接处理文件、网络或数据库操作
- **依赖关系**：通过 `AppController`、`ConfigManager` 单例访问 C++ 后端数据

### FormatUtils.js

界面展示格式化工具，使用 `.pragma library` 实现单例加载。

#### function formatBytes(bytes): string

**说明**：将字节数格式化为人类可读的文件大小

| 参数 | 类型 | 说明 |
|------|------|------|
| bytes | number | 字节数 |

**返回**：`string` - 格式化后的字符串（如 "1.5 MB"）

**转换规则**：< 1024 显示 B，< 1MB 显示 KB，< 1GB 显示 MB，否则显示 GB

---

#### function formatTime(timeString): string

**说明**：将时间字符串格式化为 "HH:mm" 格式

| 参数 | 类型 | 说明 |
|------|------|------|
| timeString | string | ISO 时间字符串 |

**返回**：`string` - 格式化后的时间（如 "14:30"）

## QML 调用示例

### 完整设备选择与传输流程

```qml
// Main.qml 中的核心交互
PeerListView {
    id: peerList
    selectedDeviceId: mainWindow._targetDeviceId
    onDeviceSelected: function(deviceId, deviceName, ipAddress, isOnline) {
        mainWindow.selectDevice(deviceId, deviceName, ipAddress, isOnline)
    }
    onFileDropped: function(deviceId, filePath) {
        AppController.transfer.createSendSession(deviceId, filePath)
    }
}

DeviceSessionView {
    visible: mainWindow._targetDeviceId.length > 0
    deviceId: mainWindow._targetDeviceId
    deviceName: mainWindow._targetDeviceName
    ipAddress: mainWindow._targetIpAddress
    isOnline: mainWindow._targetIsOnline
    onSendFileRequested: fileDialog.open()
    onSendFolderRequested: folderDialog.open()
    onFileDropped: function(filePath) {
        AppController.transfer.createSendSession(mainWindow._targetDeviceId, filePath)
    }
}
```

### 接收确认弹窗

```qml
Connections {
    target: AppController.transfer
    function onReceiveRequestReceived(sessionId, senderDeviceId, senderName,
                                      fileName, fileSize, totalFiles, totalBytes,
                                      isDirectory, fileList) {
        acceptDialog.sessionId = sessionId
        acceptDialog.senderName = senderName
        acceptDialog.fileName = fileName
        acceptDialog.fileSize = fileSize
        acceptDialog.totalFiles = totalFiles
        acceptDialog.totalBytes = totalBytes
        acceptDialog.isDirectory = isDirectory
        acceptDialog.fileList = fileList
        acceptDialog.open()
    }
}
```

## 数据流

### 设备选择与会话展示流程

```
用户点击设备卡片
    → DeviceCard.cardClicked 信号
    → PeerListView.deviceSelected 信号
    → mainWindow.selectDevice() 更新 _targetDevice*
    → DeviceSessionView 重新绑定 deviceId
    → 按 deviceId 筛选 TransferSessionManager.sessions
    → 显示该设备的传输记录列表
```

### 文件拖拽传输流程

```
用户拖拽文件到设备卡片
    → DropArea.onDropped
    → 提取文件路径（去掉 file:// 前缀）
    → DeviceCard.fileDropped 信号
    → PeerListView.fileDropped 信号
    → mainWindow.selectDevice() 选中目标设备
    → AppController.transfer.createSendSession(deviceId, filePath)
```

### 接收确认流程

```
TransferSessionManager 发射 receiveRequestReceived
    → Main.qml Connections 捕获信号
    → 自动选中发送方设备
    → 填充 AcceptDialog 属性
    → acceptDialog.open()
    → 用户点击"接受"
    → AcceptDialog.onAccepted
    → AppController.transfer.acceptReceiveSession(sessionId)
```
