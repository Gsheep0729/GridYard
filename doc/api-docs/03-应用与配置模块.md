## 概述

- **模块职责**：应用全局控制与配置管理，组装和持有下层业务模块，向 QML 暴露统一入口
- **核心类**：
  - `AppController`（`src/client/core/app_controller.h`）
  - `ConfigManager`（`src/client/core/config_manager.h`）
  - `Logger`（`src/client/core/logger.h`）
- **模块边界**：AppController 是中介者单例，负责模块组装和生命周期；ConfigManager 管理设备身份和用户偏好；Logger 拦截 Qt 日志输出到文件。不直接处理网络协议和文件传输细节
- **依赖关系**：AppController 持有 `DiscoveryService`、`TransferSessionManager`、`P2pServer`、`ConfigManager`；被 QML 通过单例访问

## 公共接口

### AppController

QML 单例，应用全局控制器。

#### Q_PROPERTY

| 属性 | 类型 | READ | NOTIFY | 说明 |
|------|------|------|--------|------|
| applicationName | QString | applicationName | — (CONSTANT) | 应用名称 |
| applicationVersion | QString | applicationVersion | — (CONSTANT) | 应用版本号 |
| discovery | DiscoveryService* | discovery | — (CONSTANT) | 设备发现服务实例 |
| transfer | TransferSessionManager* | transfer | — (CONSTANT) | 传输会话管理器实例 |
| chat | ChatManager* | chat | — (CONSTANT) | 在线聊天管理器实例 |

#### static AppController *AppController::create(QQmlEngine *engine, QJSEngine *scriptEngine)

**说明**：QML_SINGLETON 必需的工厂方法，引擎调用，外界不应直接 new

| 参数 | 类型 | 说明 |
|------|------|------|
| engine | QQmlEngine* | QML 引擎 |
| scriptEngine | QJSEngine* | JS 引擎 |

**返回**：`AppController*` - 单例实例

### ConfigManager

QML 单例，使用 QSettings 管理应用配置。

#### Q_PROPERTY

| 属性 | 类型 | READ | WRITE | NOTIFY | 说明 |
|------|------|------|-------|--------|------|
| deviceId | QString | deviceId | — | deviceIdChanged | 本机设备 UUID（只读） |
| deviceName | QString | deviceName | setDeviceName | deviceNameChanged | 本机显示名称 |
| localIp | QString | localIp | — | localIpChanged | 当前本机 IPv4 地址（只读） |
| receivePath | QString | receivePath | setReceivePath | receivePathChanged | 接收文件保存目录 |
| autoAcceptFiles | bool | autoAcceptFiles | setAutoAcceptFiles | autoAcceptFilesChanged | 是否跳过确认直接保存 |
| tcpPort | quint16 | tcpPort | setTcpPort | tcpPortChanged | TCP P2P 服务监听端口 |

#### static ConfigManager *ConfigManager::create(QQmlEngine *engine, QJSEngine *scriptEngine)

**说明**：QML_SINGLETON 工厂方法，使用静态变量实现单例模式

| 参数 | 类型 | 说明 |
|------|------|------|
| engine | QQmlEngine* | QML 引擎 |
| scriptEngine | QJSEngine* | JS 引擎 |

**返回**：`ConfigManager*` - 单例实例

## QML 调用示例

### 获取应用信息

```qml
Label {
    text: "%1 v%2".arg(AppController.applicationName)
                   .arg(AppController.applicationVersion)
}
```

### 读取和修改配置

```qml
// 读取
Label { text: ConfigManager.deviceName }
Label { text: ConfigManager.localIp }

// 修改
TextField {
    text: ConfigManager.deviceName
    onEditingFinished: {
        let trimmed = text.trim()
        if (trimmed.length > 0)
            ConfigManager.deviceName = trimmed
    }
}
```

### 打开文件夹

```qml
Button {
    text: "打开下载目录"
    onClicked: ConfigManager.openFolder(ConfigManager.receivePath)
}
```

### 退出应用

```qml
onClosing: AppController.quit()
```

## 数据流

### 应用启动流程

```
main.cpp
    → QGuiApplication + QQmlApplicationEngine
    → 加载 Main.qml
    → AppController::create() 被引擎调用
    → 构造 ConfigManager（读取 QSettings 持久化配置）
    → 构造 DiscoveryService（启动 UDP 广播）
    → 构造 P2pServer（启动 TCP 监听）
    → 构造 TransferSessionManager（连接 P2pServer 信号）
    → Logger::init() 安装日志处理器
    → emit appReady()
```

### 配置修改流程

```
用户在 SettingsDialog 修改配置
    → ConfigManager.setDeviceName("新名称")
    → QSettings 持久化
    → emit deviceNameChanged()
    → QML 绑定自动更新
    → DiscoveryService 收到信号，下次广播使用新名称
```
