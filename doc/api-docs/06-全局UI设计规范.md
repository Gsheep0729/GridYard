## 概述

本文档定义 GridYard 客户端全局 UI 设计规范，所有 QML 组件必须遵循。样式常量集中在 `src/client/utils/Style.js` 中管理，禁止在组件内硬编码颜色、圆角或间距值。

**规范来源**：`src/client/utils/Style.js`

## 2. 圆角规范

统一使用 4 级圆角，禁止随意定义圆角值。

| 级别 | 常量名 | 值 | 用途 |
|------|--------|-----|------|
| 小 | Radius.xs | 4px | 状态标签、小按钮 |
| 标准 | Radius.sm | 8px | 卡片、输入框、列表项 |
| 中 | Radius.md | 10px | 弹窗、面板 |
| 大 | Radius.lg | 12px | 大弹窗、设置页卡片 |

---

## 3. 间距规范

统一使用 4px 倍数间距系统，禁止随意写间距值。

| 级别 | 常量名 | 值 | 用途 |
|------|--------|-----|------|
| 最小 | Space.xs | 4px | 图标与文字间距、紧凑元素 |
| 小 | Space.sm | 8px | 列表项内间距、按钮内边距 |
| 标准 | Space.md | 12px | 卡片内边距、表单间距 |
| 大 | Space.lg | 16px | 区域间距、弹窗内边距 |
| 最大 | Space.xl | 20px | 页面边距、大区块分隔 |

## 4. 动画时长规范

统一使用 3 级动画时长，所有状态过渡必须使用 `Behavior` + `ColorAnimation` / `NumberAnimation`。

| 级别 | 常量名 | 值 | 用途 |
|------|--------|-----|------|
| 快速 | Motion.fast | 120ms | 微交互（图标切换、小数值变化） |
| 标准 | Motion.base | 160ms | 颜色过渡、边框变化、常规状态切换 |
| 慢速 | Motion.slow | 180ms | 进度条平滑、较大区域变化 |

### 4.1 动画曲线

- 统一使用 `Easing.OutCubic` 作为标准缓动曲线
- 进度条使用 `SmoothedAnimation` 实现平滑追赶

### 4.2 标准过渡写法

```qml
Behavior on color {
    ColorAnimation {
        duration: Style.Motion.base
        easing.type: Easing.OutCubic
    }
}
```

## 5. 交互规范

### 5.1 控件四态

所有可交互控件必须定义以下状态：

| 状态 | 视觉表现 |
|------|----------|
| 默认态 | surface 背景 + border 边框 |
| 悬停态 (hovered) | surfaceSoft 背景 + 边框加深 |
| 按下态 (pressed) | primarySoft 背景 + primary 边框 |
| 禁用态 (disabled) | 降低 opacity 至 0.5-0.6 |

### 5.2 弹窗规范

- 统一使用 `Dialog` 组件
- 背景：surface 色 + Radius.md 圆角 + border 边框
- 遮罩：modal = true
- 关闭策略：`Popup.CloseOnEscape | Popup.CloseOnPressOutside`

### 5.3 提示信息规范

| 类型 | 背景色 | 文字色 | 自动关闭 |
|------|--------|--------|----------|
| 成功提示 | success | #FFFFFF | 3 秒 |
| 错误提示 | error | #FFFFFF | 3 秒 |
| 警告提示 | warning | #FFFFFF | 3 秒 |
