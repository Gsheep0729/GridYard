## 概述

- **模块职责**：定义应用层 TLV 通信协议（Type 码、帧格式、错误码），提供帧编解码器处理粘包/半包
- **核心类**：
  - `FrameCodec`（`src/shared/frame_codec.h`）
  - `gy::protocol` 命名空间（`src/shared/protocol.h`）
- **模块边界**：只负责帧级别的编解码和协议常量定义，不涉及业务逻辑（会话管理、文件 I/O）
- **依赖关系**：被 `FileSenderWorker`、`FileReceiverWorker`、`P2pServer` 使用；`protocol.h` 被所有网络层模块引用

## 数据类型

### gy::protocol 命名空间常量

#### 帧格式常量

| 常量 | 类型 | 值 | 说明 |
|------|------|-----|------|
| kHeaderBytes | quint32 | 8 | 帧头总长度（uint32 Type + uint32 Length，大端序） |
| kMaxPayloadBytes | quint32 | 256MB | 最大帧载荷长度 |

#### 分级 Payload 上限

| 常量 | 类型 | 值 | 说明 |
|------|------|-----|------|
| kMaxControlPayloadBytes | quint32 | 1MB | 控制帧最大 Payload |
| kMaxDataPayloadBytes | quint32 | 256MB | 数据帧（kTypeDataChunk）最大 Payload |

#### 协议版本

| 常量 | 类型 | 值 | 说明 |
|------|------|-----|------|
| kProtocolVersion | quint16 | 0x0100 | 协议完整版本号（高 8 位主版本，低 8 位次版本） |
| kProtocolMajorVersion | quint8 | 1 | 主版本号 |
| kProtocolMinorVersion | quint8 | 0 | 次版本号 |

#### 版本提取函数

```cpp
inline constexpr quint8 majorVersion(quint16 version);  // 提取主版本号
inline constexpr quint8 minorVersion(quint16 version);  // 提取次版本号
```

#### 网络端口

| 常量 | 类型 | 值 | 说明 |
|------|------|-----|------|
| kDefaultDiscoveryPort | quint16 | 45678 | UDP 设备发现端口 |
| kDefaultP2pPort | quint16 | 35100 | TCP P2P 文件传输端口 |

#### V1.0 Type 码

| 常量 | 值 | 方向 | 说明 |
|------|-----|------|------|
| kTypeHello | 0x0001 | UDP 广播 | 设备上线 / 心跳 |
| kTypeTransferReq | 0x0101 | TCP | 文件元数据握手请求 |
| kTypeTransferRsp | 0x0102 | TCP | 握手响应（接受/拒绝） |
| kTypeDataChunk | 0x0201 | TCP | 文件数据分块 |
| kTypeChunkAck | 0x0301 | TCP | 单文件完成确认与校验 |
| kTypeTransferDone | 0x0302 | TCP | 全部文件发送完毕 |
| kTypeCancel | 0x0401 | TCP | 取消本次传输 |

#### Payload 上限查询

```cpp
inline constexpr quint32 maxPayloadForType(quint32 type);
```

**说明**：获取指定 Type 的最大 Payload 长度。kTypeDataChunk 允许 256MB，其他帧限制为 1MB。

### gy::protocol::ErrorCode

协议错误码枚举，用于 TransferRsp / ChunkAck 帧中的错误传递。

| 枚举值 | 数值 | 说明 |
|--------|------|------|
| Success | 0 | 成功 |
| ConnectionTimeout | 1001 | 连接超时 |
| ConnectionLost | 1002 | 连接断开 |
| TransferTimeout | 1003 | 传输超时 |
| InvalidFrame | 2001 | 无效帧格式 |
| FrameTooLarge | 2002 | 帧载荷超限 |
| InvalidPayload | 2003 | 无效载荷内容 |
| ProtocolMismatch | 3001 | 协议版本不匹配 |
| InvalidFileName | 3002 | 无效文件名称 |
| InvalidFilePath | 3003 | 无效文件路径 |
| FileListMismatch | 3004 | 文件列表数量不一致 |
| DiskWriteFailed | 4001 | 磁盘写入失败 |
| DiskSpaceInsufficient | 4002 | 磁盘空间不足 |
| Sha256Mismatch | 4003 | SHA-256 校验失败 |
| UserRejected | 5001 | 用户拒绝 |
| UserCancelled | 5002 | 用户取消 |
| UnknownError | 9999 | 未知错误 |

**错误码分段**：
- 0：成功
- 1xxx：连接与传输超时
- 2xxx：帧格式错误
- 3xxx：协议与文件校验
- 4xxx：磁盘 I/O 错误
- 5xxx：用户操作
- 9999：兜底

## 公共接口

### FrameCodec

TLV 帧编解码器，含粘包/半包状态机。

#### FrameCodec::FrameCodec(QObject *parent)

**说明**：构造函数

| 参数 | 类型 | 说明 |
|------|------|------|
| parent | QObject* | 父对象 |

---

#### static QByteArray FrameCodec::encode(quint32 type, const QByteArray &payload)

**说明**：将 type + payload 编码为完整 TLV 帧字节流（含 8 字节帧头，大端序）

| 参数 | 类型 | 说明 |
|------|------|------|
| type | quint32 | 帧类型码 |
| payload | QByteArray | 帧载荷 |

**返回**：`QByteArray` - 编码后的完整帧字节流

**线程安全**：是，纯函数，无内部状态

**帧格式**：
```
+----------------+----------------+------------------+
| Type (4 bytes) | Length (4 bytes)| Payload (Length) |
|   大端序       |    大端序       |                  |
+----------------+----------------+------------------+
```

---

#### void FrameCodec::feed(const QByteArray &data)

**说明**：将 socket 收到的新数据喂入解码器，内部状态机处理粘包和半包，遇到完整帧时发射 frameReady 信号

| 参数 | 类型 | 说明 |
|------|------|------|
| data | QByteArray | socket 收到的原始字节 |

**线程安全**：否，须在持有者所在线程调用

**状态机**：
- `WaitingHeader`：累积 8 字节帧头
- `WaitingPayload`：累积 Length 字节载荷
- 完整帧就绪后发射 `frameReady`，回到 `WaitingHeader`

## 数据流

### 编码流程（发送端）

```
FileSenderWorker 需要发送帧
    → FrameCodec::encode(type, payload)
    → 生成 8 字节帧头（Type + Length 大端序）+ payload
    → socket->write(encodedData)
```

### 解码流程（接收端）

```
socket readyRead 信号
    → socket->readAll()
    → FrameCodec::feed(data)
    → 状态机累积数据
    → 完整帧就绪
    → emit frameReady(type, payload)
    → Worker::onFrameReady() 处理业务逻辑
```

### 协议版本协商流程

```
发送端构建 Hello 包
    → 包含 protocolVersion = kProtocolVersion (0x0100)

接收端收到 Hello
    → majorVersion(remote) != majorVersion(local)
    → 拒绝连接，emit errorOccurred(ProtocolMismatch)
    → majorVersion 相同，minorVersion 不同
    → 安全降级，允许连接
```
