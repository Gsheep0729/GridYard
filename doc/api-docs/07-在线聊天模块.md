## 概述

- **模块职责**：实现局域网在线设备之间的 P2P 文本聊天，复用设备发现与 TCP 通道，不依赖服务端
- **核心类**：
  - `ChatManager`（`src/client/core/chat_manager.h`）— 连接与内存会话管理
  - `ChatConnection`（`src/client/network/chat_connection.h`）— 单条 TCP 聊天连接
  - `ChatMessageModel`（`src/client/core/chat_message_model.h`）— QML 消息列表模型
  - `gy::ChatMessage`（`src/shared/chat_message.h`）— 消息值类型
  - `gy::ChatMessageCodec`（`src/shared/chat_message.h`）— JSON 编解码
- **模块边界**：`ChatManager` 只负责在线文本收发、连接复用和内存消息模型；成功收发后通过 `messageToPersist(record)` 把领域记录交给 `AppController`，由本地数据层异步保存。离线投递、群聊和账号漫游不在本模块范围
- **依赖关系**：依赖 `ConfigManager`（本机身份）、`DiscoveryService`（在线端点查询）、`P2pServer`（入站聊天 socket）、`FrameCodec`（TLV 编解码）；被 `AppController` 持有并暴露给 QML

## 数据类型

### gy::ChatMessage

在线聊天消息的内存表示。

| 字段 | 类型 | 说明 |
|------|------|------|
| messageId | QString | 消息唯一标识（UUID） |
| fromDeviceId | QString | 发送方设备标识 |
| fromName | QString | 发送方显示名称 |
| content | QString | UTF-8 文本内容（最大 4,000 字符） |
| sentAt | QDateTime | 发送时间（UTC） |

---

### gy::ChatMessageError

聊天消息处理失败分类。

| 枚举值 | 说明 |
|--------|------|
| None | 无错误 |
| InvalidInput | 输入无效（空白内容、超长等） |
| PeerOffline | 对端设备离线 |
| ConnectionFailed | 连接建立失败 |
| WriteFailed | 消息写入 socket 失败 |
| ConnectionLost | 连接中断 |
| InvalidPayload | 无效 JSON 载荷 |

---

### ChatMessageModel::Role

QML ListView 使用的角色枚举。

| 角色 | 值 | 说明 |
|------|-----|------|
| MessageIdRole | Qt::UserRole + 1 | 消息 ID |
| DeviceIdRole | — | 对端设备 ID |
| SenderNameRole | — | 发送方名称 |
| ContentRole | — | 消息内容 |
| SentAtRole | — | 发送时间 |
| IsOutgoingRole | — | 是否为发出的消息 |
| StatusRole | — | 发送状态（0=发送中，1=已发送，2=失败） |

## QML 调用示例

### 发送文本消息

```qml
// DeviceSessionView.qml 中的文本 Composer
TextField {
    id: messageInput
    placeholderText: deviceSessionView.isOnline ? qsTr("输入消息") : qsTr("设备离线，无法发送")
    enabled: deviceSessionView.isOnline
    Keys.onReturnPressed: function(event) {
        if (!(event.modifiers & Qt.ShiftModifier)) {
            deviceSessionView.sendChatMessage()
            event.accepted = true
        }
    }
}

Button {
    enabled: deviceSessionView.canSendChat
    onClicked: deviceSessionView.sendChatMessage()
}

// sendChatMessage() 实现
function sendChatMessage(): void {
    if (!canSendChat) return
    AppController.chat.sendText(deviceId, messageInput.text)
    messageInput.clear()
    chatError = ""
}
```

### 绑定聊天消息模型

```qml
ListView {
    model: AppController.chat.messageModelForDevice(deviceId)
    delegate: Item {
        required property string senderName
        required property string content
        required property string sentAt
        required property bool isOutgoing
        required property int status
        // ... 气泡渲染
    }
}
```

### 监听发送失败

```qml
Connections {
    target: AppController.chat
    function onSendFailed(deviceId, error, errorMessage) {
        deviceSessionView.chatError = errorMessage
    }
}
```

## 数据流

### 消息发送流程

```
用户在 Composer 输入文本并按 Enter
    → DeviceSessionView.sendChatMessage()
    → AppController.chat.sendText(deviceId, content)
    → ChatManager 创建 ChatMessage（UUID、fromDeviceId、fromName、content、sentAt）
    → 内存模型 appendMessage（状态 = Pending）
    → emit messagesChanged(deviceId)
    → ChatManager::connectionForDevice(deviceId)
        → 已有可用连接：复用
        → 无连接：查询 DiscoveryService 端点，创建 ChatConnection，connectToHost
    → ChatConnection::sendMessage(message)
    → FrameCodec::encode(kTypeChatText, jsonPayload)
    → socket->write(encodedFrame)
    → emit messageWritten(messageId)
    → 更新内存模型状态为 Sent
```

### 消息接收流程

```
P2pServer 收到 TCP 连接
    → monitorFirstFrame() 等待首个完整 TLV 帧
    → routeFirstFrame() 检查 Type
        → kTypeChatText：emit chatConnectionReceived(socket)
    → ChatManager::onChatConnectionReceived(socket)
    → 创建 ChatConnection，adoptSocket(socket)
    → socket readyRead → FrameCodec::feed()
    → 完整帧 → onFrameReady(kTypeChatText, payload)
    → ChatMessageCodec::decode(payload)
    → emit messageReceived(message)
    → ChatManager::onMessageReceived()
    → 去重（messageId 主键）
    → appendMessage（状态 = Sent，isOutgoing = false）
    → emit messagesChanged(deviceId)
    → QML ListView 自动刷新
```

### 连接复用与清理流程

```
ChatManager 维护 _connections 哈希表
    → connectionForDevice(deviceId) 优先查找已有连接
    → 已有连接 isUsable() == true：直接复用
    → 已有连接不可用：移除并创建新连接
    → ChatConnection::disconnected() 信号
    → ChatManager::removeConnection() 清理
    → 下次发送时自动重建连接
```
