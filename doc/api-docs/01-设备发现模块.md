## 概述

- **模块职责**：通过 UDP 广播实现局域网内设备自动发现与在线状态维护
- **核心类**：`DiscoveryService`（`src/client/network/discovery_service.h`）、`PeerInfo`（`src/shared/data_types.h`）
- **模块边界**：负责设备上线广播、心跳维护、离线剔除和对端快照查询；不涉及 TCP 文件传输和会话管理
- **依赖关系**：依赖 `ConfigManager`（本机身份配置）；被 `TransferSessionManager`（查询对端端点）和 QML（绑定设备列表）依赖

## 数据类型

### PeerInfo

局域网在线节点描述，使用 `Q_GADGET` 实现值语义，可拷贝可移动。

| 字段 | 类型 | Q_PROPERTY | 说明 |
|------|------|------------|------|
| deviceId | QString | MEMBER | 设备唯一 UUID，首次启动生成后持久化 |
| deviceName | QString | MEMBER | 用户自定义名称或系统 hostname |
| ipAddress | QString | MEMBER | 设备当前 IPv4 地址 |
| tcpPort | quint16 | MEMBER | P2P 文件传输 TCP 监听端口 |
| isOnline | bool | MEMBER | 当前是否在线 |
| protocolVersion | quint16 | MEMBER | 对端协议版本号 |
| lastSeen | QDateTime | — | 最后心跳时间（C++ 端使用） |
| lastSeenStr | QString | READ (lastSeenStr) | 格式化为 "HH:mm:ss" 的最后心跳时间 |

## 公共接口

### DiscoveryService::DiscoveryService(ConfigManager *config, QObject *parent)

**说明**：构造函数，创建 UDP socket 和定时器，启动广播监听

| 参数 | 类型 | 说明 |
|------|------|------|
| config | ConfigManager* | 本机配置来源（设备名、端口等） |
| parent | QObject* | 父对象 |

**线程安全**：否，须在主线程构造

---

### QVariantList DiscoveryService::peers() const

**说明**：获取当前在线设备列表，供 QML 绑定

**返回**：`QVariantList` - 每个元素是一个 `PeerInfo` Q_GADGET 的 QVariant 包装

**线程安全**：是，在主线程调用

---

### QVariantMap DiscoveryService::transferEndpoint(const QString &deviceId) const

**说明**：查询可用于发送传输的对端快照，目标不存在或离线时返回空 map

| 参数 | 类型 | 说明 |
|------|------|------|
| deviceId | QString | 目标设备 ID |

**返回**：`QVariantMap`，包含 `ipAddress`、`tcpPort`、`deviceName` 等字段

**线程安全**：是，在主线程调用

---

### Q_INVOKABLE void DiscoveryService::refresh()

**说明**：立即发送一次广播并清理离线节点，供 QML 手动触发

**线程安全**：否，须在主线程调用

---

## 信号

### void DiscoveryService::peersChanged()

**触发时机**：节点列表发生增删或状态变化时

---

### void DiscoveryService::nodeDiscovered(const QString &deviceId)

**触发时机**：发现新节点上线

| 参数 | 类型 | 说明 |
|------|------|------|
| deviceId | QString | 新发现的设备 ID |

---

### void DiscoveryService::nodeExpired(const QString &deviceId)

**触发时机**：节点心跳超时被剔除

| 参数 | 类型 | 说明 |
|------|------|------|
| deviceId | QString | 离线的设备 ID |

## QML 调用示例

### 绑定设备列表

```qml
ListView {
    model: AppController.discovery.peers
    delegate: DeviceCard {
        deviceId: model.deviceId
        deviceName: model.deviceName
        ipAddress: model.ipAddress
        isOnline: model.isOnline
    }
}
```

### 手动刷新

```qml
Button {
    text: "刷新"
    onClicked: AppController.discovery.refresh()
}
```

### 监听设备上线

```qml
Connections {
    target: AppController.discovery
    function onNodeDiscovered(deviceId) {
        console.log("新设备上线:", deviceId)
    }
    function onNodeExpired(deviceId) {
        console.log("设备离线:", deviceId)
    }
}
```

## 数据流

### 设备发现流程

```
应用启动
    → DiscoveryService 构造
    → 绑定 UDP 45678 端口
    → 每 5 秒发送 Hello 广播（含 deviceId、deviceName、tcpPort、protocolVersion）
    → 收到其他设备的 Hello 包
    → 解析 JSON，更新 _peers 哈希表
    → emit peersChanged()
    → QML 自动刷新设备列表
```

### 离线剔除流程

```
每 15 秒触发 pruneOfflineNodes()
    → 遍历 _peers，检查 lastSeen 距今是否超过 15 秒
    → 超时节点标记 isOnline = false
    → emit nodeExpired(deviceId)
    → emit peersChanged()
```

### 对端查询流程（供发送使用）

```
TransferSessionManager 需要发送文件
    → 调用 discovery->transferEndpoint(deviceId)
    → 从 _peers 哈希表查找目标设备
    → 返回 { ipAddress, tcpPort, deviceName } 快照
    → 目标不存在或离线时返回空 map
```
