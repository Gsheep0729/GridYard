## 概述

- **模块职责**：管理所有进行中的传输会话（发送和接收），协调 FileSenderWorker 和 FileReceiverWorker 完成文件传输
- **核心类**：
  - `TransferSessionManager`（`src/client/core/transfer_session_manager.h`）
  - `FileSenderWorker`（`src/client/network/file_sender_worker.h`）
  - `FileReceiverWorker`（`src/client/network/file_receiver_worker.h`）
  - `FileEntry`、`TransferSession`（`src/shared/data_types.h`）
  - `FileItem`（`src/client/core/dir_serializer.h`）
- **模块边界**：负责会话生命周期管理（创建、接受、拒绝、取消、移除）和 Worker 调度；不涉及设备发现和协议编解码细节
- **依赖关系**：依赖 `ConfigManager`（本机配置）、`DiscoveryService`（对端查询）、`P2pServer`（入站请求）、`FrameCodec`（帧编解码）；被 `AppController` 持有并暴露给 QML

## 数据类型

### FileEntry

文件元数据，用于传输请求中的文件描述。

| 字段 | 类型 | Q_PROPERTY | 说明 |
|------|------|------------|------|
| relativePath | QString | MEMBER | 相对路径（含目录结构） |
| fileSize | qint64 | MEMBER | 文件大小（字节） |
| sha256 | QString | MEMBER | 文件哈希（传输完成后校验用） |

### TransferSession

传输会话状态。

| 字段 | 类型 | Q_PROPERTY | 说明 |
|------|------|------------|------|
| sessionId | QString | MEMBER | 会话唯一 ID |
| peerDeviceId | QString | MEMBER | 对端设备 ID |
| fileCount | int | MEMBER | 文件数量 |
| totalBytes | qint64 | MEMBER | 总字节数 |
| sentBytes | qint64 | MEMBER | 已发送字节数 |
| isActive | bool | MEMBER | 是否活跃 |

### gy::FileItem

文件条目信息（DirSerializer 使用）。

| 字段 | 类型 | 说明 |
|------|------|------|
| relativePath | QString | 相对于根目录的路径 |
| sizeBytes | qint64 | 文件大小（字节） |
| sha256 | QString | hex 编码的 SHA-256 |

## 公共接口

### TransferSessionManager

#### QVariantList TransferSessionManager::sessions() const

**说明**：获取当前所有传输会话列表，供 QML 绑定

**返回**：`QVariantList` - 每个元素是一个包含 sessionId、type、fileName、status、progress 等字段的 QVariantMap

**线程安全**：是，在主线程调用

---

#### void TransferSessionManager::init(ConfigManager *config, DiscoveryService *discovery, P2pServer *p2pServer)

## QML 调用示例

### 发起文件传输

```qml
AppController.transfer.createSendSession(
    targetDeviceId,
    "/home/user/document.pdf"
)
```

### 监听传输完成

```qml
Connections {
    target: AppController.transfer
    function onTransferCompleted(sessionId, fileName, filePath) {
        console.log("传输完成:", fileName)
    }
}
```

### 监听接收请求

```qml
Connections {
    target: AppController.transfer
    function onReceiveRequestReceived(sessionId, senderDeviceId, senderName,
                                      fileName, fileSize, totalFiles, totalBytes,
                                      isDirectory, fileList) {
        acceptDialog.sessionId = sessionId
        acceptDialog.senderName = senderName
        acceptDialog.fileName = fileName
        acceptDialog.open()
    }
}
```

### 取消传输

```qml
Button {
    text: "取消"
    onClicked: AppController.transfer.cancelSession(sessionId)
}
```

## 数据流

### 发送流程

```
用户选择文件
    → AppController.transfer.createSendSession(deviceId, filePath)
    → TransferSessionManager 查询对端端点 (transferEndpoint)
    → 创建 FileSenderWorker，moveToThread
    → Worker::startTransfer(host, port, path, senderId, senderName)
    → DirSerializer::serialize(path) 遍历文件列表
    → 建立 TCP 连接
    → 发送 TransferReq（JSON：sessionId、senderName、files、totalBytes）
    → 等待 TransferRsp
    → 接受后逐文件发送 DataChunk（8MB 分块）
    → 每个文件完成后等待 ChunkAck（SHA-256 校验）
    → 全部完成发送 TransferDone
    → emit transferFinished(true)
```

### 接收流程

```
P2pServer 收到 TCP 连接
    → 创建 FileReceiverWorker + QThread
    → socket moveToThread
    → Worker::initialize() 在后台线程初始化
    → 收到 TransferReq 帧
    → 解析 JSON，构建请求快照
    → emit transferRequestReceived(request)
    → TransferSessionManager 转发信号
    → QML 显示 AcceptDialog
    → 用户点击"接受"
    → acceptReceiveSession(sessionId)
    → Worker::acceptTransfer()
    → 发送 TransferRsp(accepted)
    → 逐文件接收 DataChunk，写入磁盘 + 增量 SHA-256
    → 每个文件完成后发送 ChunkAck(verified)
    → 收到 TransferDone
    → emit transferFinished(true, savedPath)
```
